# EARTHFLIGHT

## Why?
This project is here because there was not a simple Google Earth style viewer controlled by a gamepad.

## What
The goal is to be comically simple - fire it up, use an (already-connected) gamepad. No settings screens or configuration options, tweaking means changing the code.
It was built around my Nintendo Switch Pro controller, but it reads the controller through Apple's GameController framework, so an Xbox or PlayStation controller should work the same way. Only the Switch Pro has been tried.
Teleporting to a location is done by pressing the menu button (+ on a Switch Pro) and speaking. No options, no menus, first result wins.
